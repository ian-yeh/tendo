# Tendo Landing Page

A minimalist, production-grade landing page for Tendo - Autonomous Web Testing.

## Setup

Install dependencies at the root of the monorepo:

```bash
npm install
```

## Development

Start the dev server:

```bash
npm run dev --workspace=@tendo/web
```

Open [http://localhost:3000](http://localhost:3000) to view the page.

## Build

```bash
npm run build --workspace=@tendo/web
```

## Design Direction

- **Aesthetic**: Direction-bold minimalist. Pure black and white, elegant and powerful.
- **Typography**: IBM Plex Mono (headlines) + IBM Plex Sans (body)
- **Motion**: Purposeful, subtle animations via Framer Motion
- **Philosophy**: "Action compounds, panic does not" - a testament to builders who care.

The page showcases:
- What Tendo is (autonomous web testing agent)
- Key features (visual perception, plain English, multi-step flows, reliability)
- Why it matters (for builders who refuse flaky tests)
- Links to GitHub
